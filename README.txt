THE INTELLIGENCE — STUDENT NEWSPAPER
A Digital Student Newspaper

Hi, I'm Rushil, and I created The Intelligence as a prototype for a possible student newspaper at school.

The idea is to create one central place where students across all year groups can keep up with what's happening around school, while also giving students the opportunity to contribute their own work, ideas and creativity.

What's included

The website currently includes:

Clubs & Societies — a space for clubs to advertise themselves and attract new members.
Upcoming Events — important school events, dates and information.
Hall of Fame — a showcase for outstanding student work from across the school.
Morning Briefing — a simpler summary of important morning announcements.
Past Newsletters — an archive for previous editions and newsletters.
Riddles — an interactive puzzle section.
Subject Crossword — a crossword based around school subjects and related terminology.
Digital Suggestion Box — a way for students to submit ideas, feedback and suggestions.
Why I made it

I wanted this to feel less like another school information page and more like an actual student publication.

The aim is to make school news and opportunities easier to find, while also giving students something they can actively contribute to. Different year groups could contribute articles, artwork, photography, achievements, club advertisements, puzzles and other content.

I also wanted the website to be flexible enough that its content can be updated regularly without having to redesign the whole site each time.

How it works

The website is built using HTML, CSS and JavaScript and is designed to be hosted through GitHub Pages.

There is also a content.json file and a local admin.html content manager for updating things such as clubs, events, announcements and Hall of Fame entries.

The current version is a prototype, so some of the content and newsletter files are placeholders. These could be replaced with real school content if the project is approved.

Project structure
index.html              Main newspaper website
admin.html              Local content manager
content.json            Newspaper content
assets/                 Images and other website assets
past_editions/          Previous newsletter PDFs
Important note

This is currently a student-created prototype rather than an official school publication. Any real implementation would need to follow the school's usual approval, safeguarding, privacy and content-moderation procedures.

The idea is for this to become something developed with staff and students across the school, rather than simply being a finished replacement for existing school communication systems.
